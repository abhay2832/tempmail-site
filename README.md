## 🎯 About The Project

**Aryan TempBox** ek lightning-fast aur secure temporary email service hai jo aapko spam emails se bachata hai. Chahe aapko kisi website par sign up karna ho bina apni personal email share kiye, ya fir temporary testing karni ho—yeh tool aapke liye ek clean aur minimal interface provide karta hai.

### ✨ Key Features

*   🛡️ **100% Privacy Focused:** Koi bhi personal data save nahi hota, instant disposable mail boxes.
*   ⚡ **Real-time Updates:** Incoming emails bina page refresh kiye turant screen par appear hote hain.
*   🌑 **Sleek Dark UI:** Dark-mode enthusiast ke liye specially crafted minimal aur modern look.
*   📱 **Fully Responsive:** Mobile, Tablet aur Desktop sabhi devices par seamlessly kaam karta hai.
